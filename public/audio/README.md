# Rádio MathQuest — catálogo local

Nenhuma música foi adicionada nesta entrega. O catálogo da aplicação está vazio e o player informa isso, sem faixas fictícias reproduzíveis. Não há streaming ou requisições a provedores externos.

Para disponibilizar até três músicas:

1. Adicionar aqui arquivos MP3, OGG ou WAV cujo uso/distribuição seja autorizado para o projeto.
2. Registrar em `src/data/music.ts`: ID estável, título, caminho `/audio/nome.ext`, autor, URL de origem, identificação/link da licença e atribuição exata (ou explicitamente dispensada).
3. Arquivar prova da licença junto ao arquivo e conferir as condições de redistribuição e eventual uso comercial. Licença desconhecida não é autorização.
4. Testar reprodução real, loop, pausa, volume, seleção e navegação.

O player carrega arquivos somente a partir de um comando manual de reprodução. Preferências não restauram automaticamente a reprodução ao reabrir. O volume e a faixa são lembrados; mudar de faixa pausa e aguarda novo comando.

Os efeitos sintetizados pelo próprio projeto serão documentados separadamente; não dependem deste catálogo musical.
